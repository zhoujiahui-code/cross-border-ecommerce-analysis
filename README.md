# 跨境电商订单用户价值分层与商品营收分析

## 项目背景
针对跨境零售运营粗放、客户分层与商品结构精细化分析不足的业务痛点，基于54万条原始订单数据开展全维度数据诊断，输出可落地的业务优化策略。

## 技术栈
- 数据清洗与预处理：Python (Pandas)
- 指标计算与分层分析：MySQL（窗口函数、CTE、聚合查询）
- 可视化与策略输出：FineBI

## 核心成果
1.  数据治理：完成54万条原始订单清洗，输出39万条标准化数据集，数据可用率72%
2.  指标体系：搭建销售、客户、地域、商品四大维度共12项核心指标
3.  业务诊断：识别出英国市场单一依赖、高价值客户流失两大核心风险
4.  策略输出：输出分级优化方案，模拟预估可带动GMV提升4%（约33万元）

## 核心结论
### 销售节奏
营收呈强季节性波动，Q4大促峰值达108.4万元，为平销期3倍以上；大促后环比下滑53.2%，常态化运营支撑不足。

### 客户价值
客户分层差异显著，重要价值客户以不足30%的占比贡献65.78%营收；流失客户占比26.07%，对应超两成营收缺口风险。

### 市场结构
地域集中度极高，英国单一市场贡献82.14%营收，规模为第二梯队荷兰的近30倍，单一市场依赖风险突出。

### 商品结构
品类营收分化明显，A类核心商品支撑基本盘，B/C类长尾商品动销率偏低，品类协同价值未充分释放。

## 业务优化策略
1.  **市场分散策略**：将英国市场20%运营预算转移至荷兰、澳大利亚等高增长潜力市场，分散单一市场风险。
2.  **客户召回策略**：针对重要挽留客户、流失客户定向推送召回活动，优先挽回高价值流失用户。
3.  **平销期运营**：通过月度主题活动拉动平销期营收，收窄月度营收波动幅度至30%以内。
4.  **商品协同**：优化B/C类商品连带销售策略，预计提升B/C类商品营收占比2-3个百分点。
